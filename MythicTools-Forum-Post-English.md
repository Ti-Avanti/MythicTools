# MythicTools | Make MythicMobs Easier to Configure

Do you like the power of MythicMobs but find large YAML configurations difficult to manage?

**MythicTools** is an in-game visual management plugin built around MythicMobs. It brings the core setup for drops, spawning, and Bosses into a GUI, making custom content much more approachable for server owners and staff who are not comfortable with complex configuration files.

## Why MythicTools?

MythicMobs is incredibly powerful, but configuring mob drops, biome spawning, fixed spawn points, and Boss mechanics can be intimidating for many server owners.

My goal with MythicTools is to make those common tasks easier to understand and maintain, so more servers can use MythicMobs to build RPG, survival, adventure, dungeon, and raid content.

## Main Features

- **Drop management**: Create reward groups and probability-based rewards. Item rewards can be placed directly from your inventory into the GUI and saved.
- **Spawn management**: Configure biome-based spawning and fixed spawn points, including spawn rules, amounts, ranges, and alive limits.
- **Mob groups**: Build reusable groups containing multiple MythicMobs, with configurable weights and total spawn amounts.
- **Boss management**: Configure Boss phases, spawn points, announcements, killer rewards, and damage-ranking rewards.
- **In-game GUI**: Create, edit, delete, and organize core configurations without repeatedly editing YAML by hand.
- **Localization**: Built-in Chinese and English support, with MiniMessage and legacy `&` / `§` color-code compatibility.
- **Offline rewards**: Rewards can be kept for players whose inventories are full and claimed later.

## Who Is It For?

- Server owners who want to use MythicMobs without mastering complex configuration files.
- Servers that want to let staff manage drops, spawns, and Boss content more easily.
- RPG, survival, adventure, dungeon, and raid servers that want to create content faster.

## Commands

```text
/mt gui     Open the management GUI
/mt reload  Reload configurations
/mt info    View plugin status
```

## Requirements

- Paper 1.20.1, 1.20.4, or 1.21.11
- MythicMobs
- PlaceholderAPI
- PacketEvents
